# 02 · 账号、租户与计费

## 身份模型

```
User (邮箱+密码)
 └─ Membership ─→ Org (personal | team)   ← 额度、录音、订单都挂在 Org 上
                    ├─ Wallet (余额分钟)
                    ├─ LedgerEntry (台账)
                    ├─ Subscription (套餐)
                    ├─ Order (对公充值单)
                    ├─ Recording
                    └─ UsageRecord (成本)
```

- 注册即创建一个 `personal` 空间的 owner 成员关系，并赠送 `FM_SIGNUP_BONUS_MINUTES`。
- 「升级团队」= 新建一个 `team` 空间并邀请成员，额度池按空间独立；个人空间不受影响。
- 所有业务接口都要求 `X-Org-Id`（缺省用 `user.default_org_id`），服务端校验成员关系，越权返回 403。

## 角色

| 角色 | 权限 |
|---|---|
| owner | 改名、改角色、移除成员、充值/开通套餐、删除空间所有者保护 |
| admin | 邀请成员、移除成员、充值/开通套餐 |
| member | 录音、上传、查看/删除记录、查看账单 |

## 会话

- 登录成功后返回 `vt_` 开头的一次性明文 token，服务端只存 `SHA-256(token)`。
- 默认 30 天有效；改密码会撤销该用户全部会话。
- 撤销/过期后所有接口返回 401，前端跳转 `/login?next=...`。

## 邮箱令牌

| 类型 | TTL | 用途 |
|---|---|---|
| verify | 24h | 注册验证（软验证：未验证也可用，但会提示） |
| reset | 60min | 找回密码 |
| invite | 72h | 团队邀请 |

## 计费规则

**扣费时机**：任务完成（`done`）时结算一次，失败不扣。

**计费公式**：

```
billed = max(0.5, ceil(音频秒 / 60 / 0.1) * 0.1)   # 分钟，向上取整到 0.1
```

**台账类型**：

| kind | 说明 |
|---|---|
| `grant` | 注册赠送、套餐周期发放 |
| `topup` | 充值到账（订单确认） |
| `consume` | 任务扣费（负值） |
| `adjust` | 运营手工调整/补偿 |
| `refund` | 退款 |

每条台账都记录 `balance_after`，可直接对账。

**套餐种子**（`billing.py:DEFAULT_PLANS`，可在库中改）：

| code | 价格 | 额度 | 周期 |
|---|---|---|---|
| free | $0 | 60 分钟 | 30 天 |
| pro | $9.9 | 600 分钟 | 30 天 |
| team | $29 | 2000 分钟 | 30 天 |

分钟包：60 分钟 $1.2 / 300 分钟 $6 / 1000 分钟 $20（`TOPUP_PACKS`）。

**对公转账流程**：

1. 客户在「账单」页提交充值单（分钟数 × 单价）。
2. 客户按「对公账户」信息转账，备注订单号。
3. 运营在 `/admin` → 订单 → 填实际到账分钟数 → 确认到账。
4. 系统写 `topup` 台账、充值钱包、发邮件通知；订阅单同时创建/替换 `Subscription` 并发放周期额度。

## 成本与毛利

`UsageRecord` 每任务记录：音频秒数、ASR 成本（¥）、LLM 估算成本（¥）、计费分钟。
运营后台「用量与毛利」按空间聚合：`收入 = 分钟 × 单价(USD)`，`毛利 = 收入 − 成本/7.2`。

## 额度不足

创建录音、上传、触发转写前都会检查余额，不足返回 **402**，前端提示充值。
余额低于 `FM_LOW_BALANCE_WARN_MINUTES` 时 `summary.low_balance = true`。
