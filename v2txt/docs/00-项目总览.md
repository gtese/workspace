# 00 · 项目总览（V2TXT 商业化版）

## 定位

面向海外 / 港澳台客户的 SaaS：**录音 → 转写（发言人区分）→ 中英纪要 → 分享/交付**。
按用量计费（订阅套餐 + 分钟包），以个人账号起步、可升级团队共享额度。

> 旧的 `feishu-voice-recorder`（Trace Voice）已归档，代码与文档保留在 `docs/archive/`，不再维护。

## 与 v1 的关键差异

| 维度 | v1（Trace Voice，公司内部） | v2（V2TXT，商业化） |
|---|---|---|
| 用户 | 飞书免登，open_id 即身份 | 邮箱+密码自助注册，可换绑团队 |
| 租户 | 单用户 | 个人空间 / 团队空间，成员与角色 |
| 计费 | 无 | 订阅套餐 + 分钟钱包 + 台账 + 对公订单 |
| 入口 | 固定公网 IP + Let's Encrypt | Cloudflare Tunnel，零公网暴露、零 NAT |
| 录音来源 | 网页录音 | 网页录音、整文件上传、（v1.1）会议机器人 |
| 交付 | 飞书文档/卡片 | 签名分享链接、邮件、（可选）飞书通道 |
| 运营 | 无 | 运营后台：用户/订单/额度/毛利 |

## 架构

```
                    ┌──────────────── Cloudflare 边缘（TLS 终结）────────────────┐
浏览器 ─HTTPS─→ app.v2txt.cn ─→ cloudflared（内网出站长连接）─→ 127.0.0.1:8080
                                                                     │
                                                        ┌────────────▼────────────┐
                                                        │ FastAPI 容器（uid 1000） │
                                                        │  · 账号/团队/计费 API     │
                                                        │  · 录音分段/上传          │
                                                        │  · DB 队列 worker ×2      │
                                                        └───┬─────────┬───────────┘
                                                            │         │
                              SQLite/Postgres ──────────────┘         ├─→ 阿里云 DashScope（ASR / LLM）
                              data/recordings（30 天）                 └─→ SMTP（纪要邮件）
```

- 单容器应用 + 内置 worker 线程；无 Redis、无 Celery，部署极简。
- 音频保留 30 天后由 maintenance 线程清理；转写完成即把 WAV 压成 m4a 并删分段。
- 凭据只存在于宿主机 `~/.mm/`（700/600），容器只读挂载，仓库零凭据。

## 飞书接入

- 应用：`cli_ab8c83e014b99cfb`（自建应用），凭据在 `~/.mm/feishu-v2txt`。
- 登录入口：`/login` 的「飞书登录」，浏览器走 OAuth，飞书客户端走 `tt.requestAuthCode` 免登。
- 组织映射：同一 `tenant_key` 自动归入同一个团队空间；首个登录者为 owner 并发放试用额度，后续成员自动加入为 member。
- 已有邮箱账号若邮箱与飞书邮箱一致，会合并身份（保留密码登录，可双通道）。
- 纪要同步到飞书文档/卡片默认关闭（需 `drive`/`docx`/`im` 权限），用 `FM_FEISHU_DOC_ENABLED` / `FM_FEISHU_CARD_ENABLED` 开启。
