# 04 · 运维手册

## 日常检查

```bash
cd ~/v2txt
docker compose ps
curl -fsS http://127.0.0.1:8080/health
docker compose logs --since=1h api | grep -E "ERROR|结算失败|转写任务失败" | tail
```

`/api/v1/ops/health`（`X-Ops-Token`）返回：`db_ok`、录音数、队列积压、磁盘余量、最近失败数。

## 定时任务

| 任务 | 频率 | 实现 |
|---|---|---|
| 清理过期音频（`FM_RETENTION_DAYS`） | 每 `FM_RETENTION_CHECK_SECONDS` | maintenance 线程 |
| 清理孤儿目录 | 同上 | maintenance 线程 |
| 重新入队中断任务 | 启动时 + watchdog | `requeue_interrupted()` |
| 备份 | 建议每日 04:00 | 宿主 cron 调 `make backup` |

宿主 cron 示例：

```cron
0 4 * * * cd /home/user/v2txt && docker compose exec -T api python scripts/backup.py --out /app/data/backups --keep 14 >> /home/user/v2txt/data/backup.log 2>&1
```

## 发版流程

```bash
# 本地
.venv/bin/python -m pytest -q backend/tests
.venv/bin/ruff check .
rsync -az --delete --exclude='.venv' --exclude='data/' --exclude='.env' ./ user@172.16.50.166:~/v2txt/
# 服务器
cd ~/v2txt && docker compose build && docker compose up -d
curl -fsS http://127.0.0.1:8080/health
```

回滚：镜像 tag 化（`IMAGE_TAG=20261124`）后 `IMAGE_TAG=上一个 docker compose up -d`。

## 数据

| 路径 | 内容 |
|---|---|
| `data/app.db` | SQLite 主库 |
| `data/recordings/<rec_id>/` | 分段（转写后删除）、`merged.m4a` |
| `data/backups/` | 备份包 |
| `data/outbox/` | 历史邮件落盘（mock 模式） |

迁移到 Postgres：`docker compose --profile pg up -d db`，`.env` 设
`FM_DATABASE_URL=postgresql+psycopg://v2txt:<PG_PASSWORD>@db:5432/v2txt`，重建容器（表由 `create_all` 建）。

## 容量估算

- 音频：16k 单声道 32kbps m4a ≈ 14MB/小时；按 30 天保留需约 `日时长(小时) × 14MB × 30`。
- 单任务典型耗时：19 秒音频约 40 秒（ASR 异步 + LLM）。
- worker 并发 2 已够日均数十小时；超过后再加 `FM_WORKER_COUNT` 或独立 worker 容器。

## 故障处理

| 症状 | 排查 |
|---|---|
| 任务一直 `transcribing` | 看日志里 ASR 轮询；确认 `dashscope.aliyuncs.com` 可达 |
| 任务 `failed: FILE_DOWNLOAD_FAILED` | 阿里云拉不到音频 URL → 检查 `FM_PUBLIC_BASE_URL` 是否公网可达 |
| 登录 401 全员 | `FM_SECRET_KEY` 是否被改；会话表是否被清 |
| 邮件不发 | `FM_EMAIL_MODE=real`？SMTP 连通性？`docker compose logs api | grep 邮件` |
| 额度扣不动 | `FM_BILLING_*` 配置；看 `ledger` 是否有 `consume` |
| 磁盘涨 | `data/recordings` 是否清理；`FM_RETENTION_DAYS` |

## 安全

- 仓库零凭据；扫描：`grep -rnE "password *=|secret|api[_-]?key|AKIA|sk-|BEGIN .*PRIVATE KEY" .`
- `~/.mm` 700/600、不加入任何 git/备份仓库。
- 容器 `user: 1000`、`cap_drop: ALL`、`no-new-privileges`。
- 公网只暴露 443 → 隧道；宿主 8080 只绑内网 IP（`BIND_ADDR`）。

## 监控告警

`FM_MONITORING_ENABLED=true` + `FM_ALERT_OPEN_IDS`（飞书 open_id）时，watchdog 每
`FM_WATCHDOG_SECONDS` 检查 DB/队列/磁盘，异常发飞书文本。飞书通道未启用时只写日志。
