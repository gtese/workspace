# 运维手册

## 服务

| 服务 | 作用 | 命令 |
|---|---|---|
| `feishu-minutes` | 主 HTTP 服务（uvicorn，TLS，5266） | `systemctl restart feishu-minutes` |
| `feishu-events` | 飞书长连接事件消费 | `systemctl restart feishu-events` |

日志：`journalctl -u feishu-minutes -f`、`journalctl -u feishu-events -f`。

## 路径（服务器）

```
/opt/feishu-minutes/            代码与 venv（属主 <user>）
/opt/feishu-minutes/data        录音、SQLite、outbox
/etc/feishu-minutes/env         环境变量（0600，etc_t）
/etc/feishu-minutes/tls/        证书副本（uvicorn 读取，0600）
/etc/acme/dnspod.env            DNSPod 密钥（证书续期，0600）
/home/<user>/.mm/              飞书/阿里云/邮件凭据（0600）
```

> 仓库目录已更名为 `feishu-voice-recorder`；服务器路径与服务名保留历史命名
> `feishu-minutes`，避免中断，两者为同一系统。新部署可按新名字调整。

## 发布流程

```bash
# 本地
cd ~/deepseek/workspace/feishu-voice-recorder
git add feishu-voice-recorder && git commit -m "..."

# 服务器（示例）
tar -czf - backend/app web | ssh <user>@<server> 'tar -xzf - -C /opt/feishu-minutes --strip-components=1'
ssh <user>@<server> 'sudo systemctl restart feishu-minutes'
```

升级后检查：`curl -s https://voice.example.com:5266/health`。

## 监控与告警

- 公开探活：`curl -s https://voice.example.com:5266/health`
- 运维快照（需 token）：`curl -H "X-Ops-Token: $FM_OPS_TOKEN" https://voice.example.com:5266/api/v1/ops/health`
- 命令行：`../.venv/bin/python scripts/healthcheck.py`（异常退出码 1，可挂 cron）
- 看门狗（`FM_MONITORING_ENABLED=true`）每 5 分钟检查：队列积压、最早排队时长、24h 失败数、磁盘；
  命中后向 `FM_ALERT_OPEN_IDS` 发飞书文本告警
- Worker 并发数：`FM_WORKER_COUNT`（默认 2），任务认领为原子更新，不会重复处理

## 证书

- Let's Encrypt，DNS-01（DNSPod），有效期 90 天
- 自动续期：`/etc/cron.d/certbot-renew`（每天 03:15）+ `/opt/acme/renew-hook.sh`（复制证书并重启）
- 手动演练：`certbot renew --dry-run`

## 常见故障

| 现象 | 排查 |
|---|---|
| 卡片发送报 `230006 Bot ability is not activated` | 飞书后台开启「机器人」能力并发布版本 |
| 页面 401 / 旧版本 | 重开飞书应用；确认 HTML 返回 `Cache-Control: no-store` |
| 上传 401 | 登录态失效；前端应自动重登，否则点「登录飞书」 |
| 转写失败 | 看 `journalctl` 里阿里云任务错误；检查公网音频 URL 可达 |
| 文档没生成 | 检查 `docx:document` 权限与 `documents` 表；失败只影响文档，不影响卡片 |
| 磁盘将满 | 30 天清理 + 孤儿目录回收；`du -sh data/recordings` |
| 证书告警 | `certbot renew --dry-run`；检查 DNSPod 密钥是否有效 |

## 安全

- 凭据只在 `~/.mm/` 与 `/etc/feishu-*/`，权限 0600；仓库不含明文
- 提交前扫描：`grep -rnE "AKID|sk-|cfut_|password|secret" .`（预期只命中变量名/占位符）
- 分享链接 30 天有效，泄露即等于纪要泄露，转发需谨慎
