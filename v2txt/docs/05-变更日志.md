## 2026-11-24 · v2.0.0 商业化改造（新服务器 172.16.50.166）

### 基础设施

- 新服务器基线：Ubuntu 24.04.5、Docker 29.10.0、Compose v5.8.0。
- 修复系统 DNS（systemd-resolved 无上游 → 静态 `223.5.5.5 / 119.29.29.29`）。
- 梳理出口白名单：阿里云系 + pypi 通，docker.io / github / Cloudflare 不通。
- 基础镜像离线搬迁（python:3.12-slim / postgres:16-alpine / caddy:2-alpine），规避 docker.io 不可达。
- 项目迁移到 `/home/user/v2txt`，容器以 uid 1000 运行，`cap_drop: ALL`。

### 账号与租户（新）

- 邮箱+密码注册、登录、邮箱验证、找回密码、改密踢下线；scrypt 哈希、会话只存 SHA-256。
- 个人空间 / 团队空间模型，成员与 owner/admin/member 角色，邮件邀请。
- 删除 v1 的飞书免登与 `X-Employee-Open-Id` 兜底，所有接口按 `org_id` 隔离。

### 计费（新）

- 分钟钱包 + 台账（grant/topup/consume/adjust/refund，含 `balance_after`）。
- 套餐种子（Free/Pro/Team）+ 分钟包；订阅走人工确认后发放周期额度。
- 任务完成自动结算，记录 ASR/LLM 成本，运营后台出毛利报表。
- 余额不足在创建/上传/转写三处拦截，返回 402。

### 录入与交付

- 网页录音重写：16k 单声道 WAV、5 分钟自动分段、失败重试、放弃即删除。
- 新增整文件上传：mp3/m4a/mp4/mov 等转码入队，含大小/时长上限。
- 分享链接、撤销、访问审计、邮件交付延续并适配多租户。

### 界面（新）

- 落地页（套餐）、登录/注册/找回/验证/邀请页、控制台（录音/上传/记录/账单/团队/设置）、运营后台，中英双语。
