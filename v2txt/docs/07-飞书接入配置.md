# 07 · 飞书接入配置清单

## 一、应用权限（批量导入）

飞书开放平台 → 你的应用 → **权限管理 → 批量导入**，粘贴：

```json
{
  "scopes": {
    "tenant": [
      "tenant:tenant:readonly",
      "drive:drive",
      "docx:document",
      "im:message",
      "im:message:send_as_bot"
    ],
    "user": [
      "offline_access",
      "contact:user.base:readonly",
      "contact:user.email:readonly",
      "contact:user.employee_id:readonly"
    ]
  }
}
```

| 权限 | 身份 | 用途 | 缺失后果 |
|---|---|---|---|
| `offline_access` | user | 拿 refresh_token | **写回云盘在服务重启后失效**（会退化出 `Content transferred from v2txt` 目录） |
| `contact:user.base:readonly` | user | 登录取 open_id/姓名 | 飞书登录失败 |
| `contact:user.email:readonly` | user | 邮箱合并账号 | 老账号无法合并 |
| `contact:user.employee_id:readonly` | user | user_id（可选） | 无影响 |
| `tenant:tenant:readonly` | tenant | 企业名称→团队空间名 | 团队名显示「飞书团队」 |
| `drive:drive` | tenant | 建「AI录音」目录、移动/转交文档 | 纪要写不回云盘 |
| `docx:document` | tenant | 创建新版文档 | 无法生成纪要文档 |
| `im:message` / `im:message:send_as_bot` | tenant | 纪要卡片 | 不推卡片（`FM_FEISHU_CARD_ENABLED` 默认关） |

## 二、网页应用配置

| 配置 | 值 |
|---|---|
| H5 可信域名 | `https://app.v2txt.cn`（**不要带路径**） |
| 桌面端主页 | `https://app.v2txt.cn/app` |
| 移动端主页 | `https://app.v2txt.cn/app` |
| 重定向 URL | `https://app.v2txt.cn/feishu-callback` |

## 三、发布与授权

1. 权限加完 → **创建版本 → 发布**（不发布不生效）
2. 管理员审核通过、设置可用范围
3. 用户**退出后重新登录一次**，才会拿到带 `offline_access` 的新授权

## 四、自检

| 检查 | 方法 |
|---|---|
| 应用凭据有效 | `curl -X POST https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal -d '{"app_id":"...","app_secret":"..."}'` 返回 code=0 |
| 登录可用 | 打开 `/login` → 点「飞书登录」，页面无红字报错 |
| 写回云盘 | 录 30 秒 → 结束后检查 `我的空间 / AI录音` |
