## 计数口径

日志行 `[total] scanned=N moved=N overwritten=N failed=N dryrun=0`

| 字段 | 含义 |
|---|---|
| `scanned` | 本轮扫描到的、超过稳定期的普通文件数 |
| `moved` | 目标原本无同名，新增落地 |
| `overwritten` | 目标已有同名，被新版覆盖（旧版不可回滚） |
| `failed` | 目标目录缺失（含子目录）、或落地失败 |

## 判断路径

1. **文件没搬** → 看该文件所在目录是否在 `ALLOW_DIRS` 白名单内（17 个叶子目录及其子目录）；再看 `mmin` 是否满 `MIN_AGE`；`DRYRUN=1` 手工跑看是否列进计划。
2. **一直告警「目标目录不存在」** → 正式区缺目录，`sudo mkdir` 建好后下一轮自动搬（工具不自动建）。
3. **邮件没收到** → `nc -vz smtp.qiye.aliyun.com 25`，核对 `SMTP_PASS`；发信失败不影响迁移，以日志为准。
4. **误覆盖** → 无备份可回滚，只能联系上游重新生成；确认是否需要在交付流程上强制版本号命名。
