# 07 253 服务中心（Hub）

> 253 / trivm253（172.16.10.253，Rocky 8.10）是 v2 的固定服务中心。
> 它同时承担：L2TP 服务端（办公网接入）、OpenVPN 服务端（到 ECS 的出口隧道）、DNS、SS 订阅代理。

## 1. 组件清单

| 组件 | 作用 | 端口/地址 |
|---|---|---|
| xl2tpd/ppp0 | 办公网 L2TP 接入 | ppp0 10.10.10.1（对端 iKuai 10.10.10.10） |
| openvpn-server@egress | 到 ECS 的出口隧道服务端 | UDP 51821，tun-egress 10.99.99.1/24 |
| dnsmasq | 干净解析（白名单域名→1.1.1.1 经隧道） | 10.10.10.1:53、127.0.0.1:53 |
| dante (sockd) | SOCKS 出口（sing-box 出站） | 127.0.0.1:1080，external 10.99.99.1 |
| sing-box | 订阅 SS 入站 | 0.0.0.0:50181（aes-256-gcm） |
| nginx | 订阅分发 | 50180（/s/<token>/clash） |
| egress-routing.service | 隧道建立后恢复策略路由/标记 | oneshot |

## 2. 路由与策略

```bash
# table 100
ip route replace default dev tun-egress table 100
# 办公网流量 → 隧道
ip rule add from 10.10.10.0/24 table 100 priority 1000
# 打 mark 的进程流量（dnsmasq/dante）→ 隧道
ip rule add fwmark 100 table 100 priority 1001
# 内网/本地排除（走主表）
ip rule add from 10.10.10.0/24 to 172.16.0.0/16 lookup main priority 900
ip rule add from 10.10.10.0/24 to 10.10.10.0/24 lookup main priority 901
ip rule add from 10.10.10.0/24 to 192.168.9.0/24 lookup main priority 902
```

- 出 tunnel 的流量统一 `MASQUERADE -o tun-egress`（SNAT 为 10.99.99.1）；
- 253 自身默认路由不变（不影响 L2TP/业务）；
- 253 关闭 rp_filter、禁用 IPv6。

## 3. 订阅链路

```
Clash → SS 253:50181（sing-box）
      → socks 127.0.0.1:1080（dante，uid mark 100）
      → table 100 → tun-egress → 51821 → ECS → NAT → 互联网
DNS：sing-box → 127.0.0.1（dnsmasq）→ 隧道 → 1.1.1.1
```

## 4. 服务与自启

```bash
systemctl enable --now openvpn-server@egress dnsmasq sockd sing-box nginx egress-routing
```

## 5. 替换 ECS 时（253 不需要改）

- 新 ECS 用同一份 `ecs-egress` 客户端证书连接 58.246.51.170:51821；
- ECS 启用 `ip_forward` + `MASQUERADE 10.99.99.0/24`；
- 办公网/订阅完全无感。

## 6. 注意

- 253 是单点，建议监控（服务、隧道、DNS、磁盘、证书）；
- 修改 `/etc/resolv.conf` 后必须 `systemctl restart sockd`（dante 启动时读取）；
- 253 重启后 `egress-routing` 会等待 tun-egress 出现再恢复路由/标记；
- 订阅 token、SS 密码、私钥均不入库。
