# 脱敏说明

本目录是部署机 `/opt/newsbot` 的仓库副本，**所有凭据类内容已剥离**。本文记录脱敏边界与部署时的还原方法。

## 一、已脱敏项

### 1. 飞书自定义机器人 webhook（`config/config.yaml`）

| 群 | 字段 | 仓库内值 |
| --- | --- | --- |
| 研发部门群 | `feishu.groups.rnd.webhook` | `https://open.feishu.cn/open-apis/bot/v2/hook/<REDACTED-ROBOT-UUID>` |
| agentic 部门群 | `feishu.groups.agentic.webhook` | `https://open.feishu.cn/open-apis/bot/v2/hook/<REDACTED-ROBOT-UUID>` |
| 高管群 | `feishu.groups.exec.webhook` | `https://open.feishu.cn/open-apis/bot/v2/hook/<REDACTED-ROBOT-UUID>` |

`secret`（签名校验密钥）在原环境中为空，未做改动。

还原：从飞书群「设置 → 群机器人 → 自定义机器人」取 webhook 完整 URL，替换占位符；若机器人开启签名校验，同时填 `secret`，并把 `feishu.dry_run` 置为 `false`。

### 2. we-mp-rss 登录凭据（`scripts/sync_mp.py`）

原实现把 `username=admin&password=<明文>` 硬编码在 `get_token()`。现改为环境变量注入，默认用户名 `admin`、密码为空（空密码登录会失败，属预期的安全默认）：

```bash
WEMP_USER=admin WEMP_PASS=<部署机口令> \
  /opt/newsbot/venv/bin/python /opt/newsbot/scripts/sync_mp.py --dry-run
```

`BASE` 也改为 `WEMP_BASE` 可覆盖，默认 `http://127.0.0.1:8001`。

### 3. 微信读书 Cookie

部署机 `/opt/we-mp-rss/data/wx.lic` 保存公众号采集用的登录态 Cookie，**本次未同步、未以任何形式写入仓库**，也不建议入库。

## 二、保留未脱敏的内容（及理由）

| 内容 | 说明 |
| --- | --- |
| 内网地址 `172.16.50.122`、`http://127.0.0.1:8001` | 内网拓扑信息，与仓库其它项目（slurm / ood / dsh）口径一致，非凭据 |
| `config/mp_sources.yaml` 中的 `MP_WXS_*` feed id | 微信侧公开可寻址的公众号标识，凭据无关 |
| `scripts/sync_mp.py` 中的两个采集任务 UUID | we-mp-rss 内部任务 id，登录后可见，非凭据 |
| `ops/probe_rss.py` 的 `hook/00000000-0000-0000-0000-000000000000` | 探针脚本自带的假地址，用于格式校验 |
| 飞书签名算法说明（`src/pusher.py`、`docs/`） | 公开文档内容，不含密钥 |

## 三、复核方法

入库前对全仓 `*.py *.yaml *.md *.sh *.yml *.json` 逐行匹配以下模式，应无命中（上表"假地址"除外）：

```
password=<非空明文> | hook/<真实 UUID> | app_secret: <值>
Bearer <长 token> | xoxb- | AKIA[0-9A-Z]{16} | sk-<长串>
```

## 四、注意

- 新增群或换机器人时，**不要**把真实 webhook 提交进本仓库；仓库内始终保留占位符，真实值只改部署机。
- 若曾误提交真实凭据，应先在飞书侧重置机器人 webhook，再清理 git 历史（`git filter-repo`），仅删除文件不够。
