## 四、系统实现（已完成）

### 目录结构

```
/opt/newsbot/
├── venv/                    Python 3.9 虚拟环境
├── config/
│   ├── config.yaml          运行参数 / 飞书群 / 四类分类规则 / 排除规则
│   └── sources.yaml         新闻源清单（hint 倾向 · allow 类目白名单 · enabled 开关）
├── src/
│   ├── fetcher.py           RSS 抓取与归一化（标题/链接/摘要/时间）
│   ├── classifier.py        四类分类（锚点门槛 + 关键词加权 + 源白名单 + 排除正则）
│   ├── pusher.py            飞书自定义机器人推送（卡片 + 签名 + 文本兜底）
│   └── main.py              主流程编排
├── state/seen.json          已推送去重台账（保留 14 天）
├── logs/                    运行日志（newsbot.log / cron.log / dryrun*.txt）
└── run.sh                   定时执行入口
```

### 分类算法

1. **源级类目白名单 `allow`**：限定某来源只能进哪几类，抑制跨类噪声（如 arXiv 只进 c1/c2）。
2. **领域锚点 `anchors`**：必须命中至少一个锚点才有资格进入该类（c1 要求 AI/半导体域词，c4 要求 AI/半导体域词）。
3. **关键词加权**：标题命中 ×3、摘要命中 ×1；关键词越长越具体权重越高（≥10 字 3 分、≥6 字 2 分、其余 1 分）；来源倾向 `hint` +2。
4. **阈值**：最高分 < `min_score`(3) 视为未分类，直接丢弃。
5. **全局排除正则**：命中「万元/预售价」「市盈率/跌停/A股/债券/基金久期」「限量版/开启预售」「SUV/续航/换电」「辅助驾驶/智驾/自动驾驶/座舱」等一律丢弃。

### 推送实现

- 飞书自定义机器人 **interactive 卡片**：按类目分卡，每张卡带标题、来源、时间、摘要；失败自动降级为纯文本。
- 支持**签名校验**：`sign = base64(HMAC-SHA256(key="timestamp\nsecret", data=""))`。
- 限频：卡片间 sleep 1.2s（飞书限 5 次/秒）。
- 单轮配额：单类最多 15 条、单源最多 3 条（防止 arXiv 这类高频源刷屏），按时间倒序取最新。
