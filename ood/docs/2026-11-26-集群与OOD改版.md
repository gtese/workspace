## 四、OOD Job 查询页面（Active Jobs）

修改 Dashboard 的 Active Jobs 页面：

### 新增列
- Partition（分区）
- Host（主机/节点）
- Memory（申请内存）
- CPUs（申请 CPU 数）

### Actions
- **Stop**：取消运行/排队作业（`scancel`）
  - 管理员（group_roots / group_support）可停止任意作业；
  - 普通用户只能停止自己的作业；
  - 后端由 root helper `/usr/local/sbin/ood-jobctl` 做二次校验。
- **Delete（Remove from List）**：从当前用户 Active Jobs 列表移除该作业
  - 管理员可移除任意作业；
  - 普通用户只能移除自己的作业；
  - 说明：Slurm 20.11.9 的 `sacctmgr` 不支持删除 job 记录（实测报 “No valid entity”），因此这里的“删除”是 UI 列表移除，不是删除 Slurm 记账记录；如需彻底删除历史，需要升级 Slurm 或直接维护数据库（不建议）。

### 验证

- 普通用户 user 停止自己的测试作业成功；停止 root 的测试作业被拒绝（权限校验生效）
- OOD Rails 配置读取：`custom_css=["custom.css"]`，`stop_job` 路由存在
