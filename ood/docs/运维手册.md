# OOD 运维手册

## 1. 架构

```text
浏览器
  → Apache (edas.tri.local, mod_auth_openidc)
  → Keycloak OIDC (sso.tri.local, realm=tri, client=ood)
  → OOD Dashboard (PUN)
  → bc_desktop / VNC (TigerVNC + websockify)
  → Slurm 作业 (eda15x 或 eda)
```

## 2. 对外地址与证书

- URL：`https://edas.tri.local`
- DNS：`edas.tri.local -> 172.16.50.123`
- 证书：`*.tri.local`（覆盖 edas）

## 3. Apache / OOD 配置

`/etc/ood/config/ood_portal.yml`：

```yaml
servername: edas.tri.local
logout_redirect: '/oidc?logout=https%3A%2F%2Fedas.tri.local'
oidc_client_id: 'ood'
oidc_client_secret: <redacted>
oidc_crypto_passphrase: <redacted>
```

`/etc/ood/config/clusters.d/tricluster.yml`：

```yaml
metadata:
  url: "https://edas.tri.local"
login:
  host: "edas.tri.local"
```

修改后：

```bash
/opt/ood/ood-portal-generator/sbin/update_ood_portal
systemctl try-restart httpd
```

## 4. Keycloak client ood

- Realm：`tri`
- Client ID：`ood`
- Redirect URI：`https://edas.tri.local/*`
- Web origin：`https://edas.tri.local`
- Post logout：`https://edas.tri.local/*`
- 不需要把 client secret 写入 Git

## 5. Desktop 子应用

文件：

```text
/etc/ood/config/apps/bc_desktop/eda.yml.erb
/etc/ood/config/apps/bc_desktop/submit/ood.yml.erb
```

关键点：

- `eda.yml.erb` 是表单，文件名决定应用名，当前为 **EDA Desktop**
- 不要直接放在 `/etc/ood/config/apps/bc_desktop/` 根目录的 `form.yml` / `submit.yml.erb`，否则 OOD 会把它们当成两个子应用
- `submit.yml.erb` 必须放在 `submit/` 目录，并由表单的 `submit:` 指向

提交逻辑：

```erb
script:
  native:
    - "--nodes=1"
    - "--mem=<%= bc_mem.blank? ? 32 : bc_mem.to_i %>G"
    - "--partition=<%= bc_node == '150' ? 'eda' : 'eda15x' %>"
    - "--nodelist=172.16.50.<%= bc_node %>"
```

## 6. 节点下拉菜单

表单会在渲染时执行：

- `scontrol show node -o 172.16.50.<N>`：总内存/已用/状态
- `squeue -h -w 172.16.50.<N> -t RUNNING`：运行作业数

显示格式：

```text
151 | 总 1900G | 已用 1328G | 可用 572G | 作业 4 | MIXED
```

## 7. 用户暂存目录必须在共享存储

OOD 默认数据目录是 `~/ondemand`，而 `/home` 是节点本地盘，计算节点看不到控制节点暂存的作业文件。

当前配置：

```text
/home/<user>/ondemand -> /eda/workspace/users/<user>/ondemand
```

新增用户时要为所有 151-155 节点创建同样的软链接，否则 Desktop 作业会启动后立刻失败。

## 8. TigerVNC 兼容

OOD 自带 VNC 模板默认使用：

```text
vncserver -log vnc.log ...
```

当前 TigerVNC 1.15 不支持 `-log`，且输出格式不同。已修补 OOD gem 模板：

- 去掉 `-log`
- 将 VNC 输出写入 `vnc.log`
- 从 `New '...:N ...' desktop is ...:N` 解析显示号

对应 gem：

```text
/opt/ood/ondemand/root/usr/share/gems/3.1/ondemand/3.1.16-1/gems/ood_core-0.29.0/...
```

## 9. websockify

OOD 需要：

```text
/opt/websockify/run
```

当前 151-155 已安装 `python3-websockify` 并创建：

```bash
#!/bin/sh
exec /usr/bin/websockify "$@"
```

检查：

```bash
/opt/websockify/run --help
```

## 10. PUN 与 403

更换域名或 `OOD_ALLOWED_HOSTS` 后：

```bash
/opt/ood/nginx_stage/sbin/nginx_stage nginx_clean -f
```

否则旧 PUN 会返回：

```text
Blocked host: edas.tri.local
```

## 11. 界面定制

- 标题：`/etc/ood/config/apps/dashboard/env`
  ```bash
  OOD_DASHBOARD_TITLE="Tri EDA Cluster"
  ```
- 导航：保留 Apps/Files/Jobs/Interactive Apps，隐藏 Clusters
  - `Files` 允许上传（`OOD_UPLOAD_ENABLED=true`），禁止下载（`OOD_DOWNLOAD_ENABLED=false`）
  - `Shell` 的 manifest category 从 `Clusters` 改为 `Jobs`，显示在 Jobs 菜单
  ```ruby
  NavConfig.categories = ["Apps", "Jobs", "Interactive Apps"]
  NavConfig.categories_whitelist = true
  ```
- 中英文切换已回滚，界面保持英文

## 12. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 403 Blocked host | 旧 PUN | `nginx_clean -f` |
| 提交被拒绝，要求 --mem | OOD 提交未带内存 | 表单填写 Memory，或检查 submit 模板 |
| 会话 Completed 且无输出 | 暂存目录不在共享存储 | 检查 `~/ondemand` 软链接 |
| VNC 不启动 | TigerVNC `-log` 不兼容 | 检查 gem 模板补丁 |
| 连接时 websockify 失败 | 缺 `/opt/websockify/run` | 安装 `python3-websockify` |
| 页面仍是旧标题/旧菜单 | PUN 缓存 | `nginx_clean -f` 后刷新 |
