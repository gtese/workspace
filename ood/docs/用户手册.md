# OOD 用户手册

## 1. 登录

浏览器打开：

```text
https://edas.tri.local
```

输入 AD 域账号，完成统一身份认证。

## 2. 启动 EDA Desktop

```text
Interactive Apps → EDA Desktop
```

表单：

| 字段 | 说明 |
|---|---|
| Number of hours | 桌面最长运行小时数 |
| Node | 选择 150-155；下拉框显示总内存/已用/可用/作业数/状态 |
| Memory (GB) | 该节点内存，单位 GB，例如 32 |

> Account 已取消填写，作业自动使用用户默认账户。

点击 **Launch**。

> 桌面固定单节点运行，不需要填写分区和节点数量。

## 3. 连接桌面

在 **My Interactive Sessions** 找到对应会话：

- 状态 **Running** 时出现 **Connect to Desktop**
- 点击后在浏览器内打开 VNC 桌面
- 若状态是 **Completed**，说明该次作业已结束，需要重新 Launch

## 4. 在桌面里使用 EDA 工具

打开桌面终端：

```bash
export PATH=/eda/env/commands/bin:$PATH
export LM_LICENSE_FILE=27000@172.16.50.121
export SNPSLMD_LICENSE_FILE=27000@172.16.50.121

virtuoso &
# 或 innovus / verdi / calibre -gui
```

桌面运行节点由启动时选择的 Node 决定。

## 5. 作业数据目录

- 个人作业数据：`/eda/workspace/users/$USER`
- OOD 暂存目录：`/eda/workspace/users/$USER/ondemand`
- 不要把正式数据放在 `/home/$USER`（各节点本地、不共享）

## 6. 常见问题

### 页面 403 Blocked host

管理员更换 OOD 域名后，旧 PUN 仍在运行。管理员执行：

```bash
/opt/ood/nginx_stage/sbin/nginx_stage nginx_clean -f
```

### 提交被拒绝：要求显式指定内存

说明该作业没有带 `--mem`。OOD Desktop 已自带 Memory 字段；命令行作业请加：

```bash
#SBATCH --mem=32G
```

### 会话 Completed，没有 Connect 按钮

作业已结束。点 **Delete** 清理旧卡片，重新 Launch。

### 连接后黑屏或桌面没起来

联系管理员检查：

```bash
/var/log/ondemand-nginx/<用户名>/error.log
```

以及会话目录下的 `output.log`、`vnc.log`、`websockify.log`。
