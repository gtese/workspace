# 用户手册（普通用户）

> 适用：已部署 dsh 的 Rocky Linux 8 桌面 VM（trivm131/132/133 等）。
> 管理员部署说明见 `deployment.md`。

## 1. 启动

打开终端，输入：

```bash
dsh
```

浏览器会自动打开 DeepSeek Harness 界面，直接开始对话即可。

- 无需配置模型地址或 API Key（管理员已统一配置）。
- 如果浏览器没有自动弹出，把终端里打印的
  `http://127.0.0.1:<端口>/?token=...` 复制到浏览器打开。
- 首次启动需要初始化，稍等几秒。

## 2. 日常使用

- 在左侧栏新建/切换会话；对话会自动保存。
- 关闭浏览器标签页或关掉终端**不会丢历史对话**；下次再输入 `dsh` 可以继续。
- 历史会话保存在**当前这台 VM** 的 `~/.dsh` 下，换一台 VM 看不到另一台的历史。
- 需要让 dsh 在你的项目目录里干活时，先 `cd` 到项目目录再运行 `dsh`。

## 3. 只跑一次性任务（不开界面）

```bash
dsh --profile headless "把这个目录里的测试跑一遍，总结失败原因"
```

结果直接输出在终端。

## 4. 常用命令

| 命令 | 作用 |
|---|---|
| `dsh` | 启动 Web 界面（自动开浏览器） |
| `dsh --version` | 查看版本 |
| `dsh web --port 18080` | 指定端口启动 Web 界面 |
| `dsh --profile headless "任务"` | 一次性任务，直接输出结果 |
| `dsh plugin --profile web add <包>` | 安装插件（需要网络/内网 npm 镜像） |

## 5. 注意事项

- **不要用 `sudo dsh`**：dsh 以你的身份运行即可，不需要 root。
- 终端打印的带 token 的链接等同于你的登录凭证，**不要发给别人**。
- 不要把自己的 `dsh` 进程用 `--host 0.0.0.0` 暴露到网络上；默认只监听本机。
- 模型请求走公司内网 Open WebUI，真实的 DeepSeek Key 不在你的机器上。
- 遇到报错先记录终端输出，联系管理员；管理员可按 `troubleshooting.md` 排查。

## 6. 常见问题

**Q：输入 `dsh` 提示 `command not found` 或 `权限不够`？**
说明这台机器的入口没装好，联系管理员执行 `sudo ./scripts/add-host-link.sh`。

**Q：浏览器没打开？**
手动复制终端里的 token URL；或确认自己是在图形桌面终端里运行，而不是 SSH。

**Q：对话报模型/网络错误？**
联系管理员检查 Open WebUI（`chat.tri.local`）和共享配置 `/eda/apps/deepseek/etc/dsh.env`。

**Q：历史对话还在吗？**
在。除非你主动删除会话，或 VM 被重置/换了一台机器。
