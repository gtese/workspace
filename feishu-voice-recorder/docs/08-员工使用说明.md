# 员工使用说明（一页版）

> 发到群里或贴在工作台公告里即可。

## 一句话

开会或谈客户时，用飞书工作台里的「纪要录音」录下来，1–5 分钟后自动给你一份带待办的会议纪要。

## 怎么用

1. 打开飞书工作台 → 点「纪要录音」
2. 填个标题（比如「客户 A 需求沟通」），选场景：内部会议 / 客户沟通 / 语音速记
3. 点「开始录音」，把手机放在桌子中间
4. 结束后点「结束并生成纪要」，等 1–5 分钟，飞书会收到卡片：「纪要好啦」

## 录音小贴士

- **手机放桌面中央**，别放包里或口袋；几个人围着桌子坐，别离得太远
- **别锁屏**，录音期间保持页面在前台（切后台可能导致中断）
- 环境尽量安静，避开空调出风口、窗外马路
- 中途接了电话没关系：已录的部分不会丢，回到页面点「继续录音」接着录
- 网络不好导致某一段没传上去？点「重试上传本段」即可，不用重录
- 充电时录音更稳（长时间录音费电）

## 结果在哪看

- 飞书卡片：摘要 + 待办 + 「查看全文」按钮
- 飞书云盘 → **AI录音** 目录：自动生成的会议纪要文档（按 `AI录音-日期-姓名` 命名）
- 工作台「我的纪要」：所有历史录音，可按内容搜索
- 详情页可以：播放录音、点说话人名字改成真实姓名、复制分享链接发给别人

## 分享与隐私

- 分享链接 30 天有效，拿到链接的人不用登录也能看，**转发前确认内容**
- 录音文件保留 90 天，纪要和文字永久保留
- 只有你自己能在「我的纪要」里看到自己的录音

## 常见问题

**没弹麦克风授权？**
点浏览器/飞书的地址栏或设置里的麦克风权限，允许后刷新页面。

**录完一直转写中？**
正常 1–5 分钟；超过 10 分钟点「重新生成」。如果还是不行，把录音标题发给管理员。

**录音声音太小？**
手机离说话人近一点，或者换到安静的会议室重录。

**能录多久？**
单场建议 90 分钟以内；超过也能录，但手机发热和电量的风险更高。
