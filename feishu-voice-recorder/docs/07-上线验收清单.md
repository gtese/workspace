# 上线验收清单（Go-Live Checklist）

> 每一项都能勾选才算"可交付"。标 🔑 的需要管理员或凭据。

## A. 飞书应用

- [ ] 🔑 创建企业自建应用「纪要录音」，拿到 App ID / App Secret（存 `~/.mm/feishu-minutes`）
- [ ] 开启能力：**网页应用**（小程序已弃用，见 ADR-001）、**机器人**
- [ ] 申请 scope：`im:message:send_as_bot`（必填）；`contact:user.email:readonly`（要邮件分发时）；
  免登换 user_access_token/user_info **不需要 scope**
- [ ] 安全设置 → 重定向 URL 配置为 `https://<域名>/`（不含 `?` `#`）
- [ ] 可用范围先设「测试部门」，验证后再全公司
- [ ] 发布版本 → 管理员审核通过
- [ ] 工作台能看到入口，点开能免登（页面显示姓名）
- [ ] 未登录访问接口返回 401；飞书外打开显示登录提示

## B. 服务端

- [x] 🔑 域名解析 + HTTPS（Let's Encrypt DNS-01，2027-02-18 到期，自动续期）
- [ ] `FM_PUBLIC_BASE_URL` 设为正式域名（影响签名音频 URL 与卡片链接）
- [ ] `FM_SECRET_KEY` 换成 32 位以上随机串（会影响已签发 token，上线前定好）
- [ ] `FM_FEISHU_MODE=real`、`FM_ASR_PROVIDER=tencent`、`FM_LLM_PROVIDER=deepseek`
- [ ] 数据库：PostgreSQL 已建库；首次启动自动建表
- [ ] `docker compose up -d` 后 `/health` 返回 expected provider
- [ ] 磁盘 ≥ 50GB 可用（90 天音频 + 分段）

## C. 录音通路（真机）

- [ ] iPhone 飞书内打开 → 弹麦克风授权 → 录 30 秒 → 出纪要
- [ ] Android 飞书内打开 → 同上
- [ ] 锁屏 1 分钟再解锁：已上传段落不丢，能续录（页面出现"继续录音"）
- [ ] 弱网（限速/飞行模式切换）：失败段落重试成功，不丢整场
- [ ] 手机系统录音机录的 m4a 上传 → 转码 → 出纪要
- [ ] 90 分钟连续录音：分段完整、无内存崩溃（iOS Safari 重点看）

## D. 转写与纪要质量

- [ ] 准备 20 段真实会议（含客户沟通）跑 A/B（`python -m app.asr.cli`）
- [ ] 人名/专有名词错误率可接受（超过 10% 需要上术语表）
- [ ] 说话人分段可用（不要求实名）
- [ ] 纪要模板：会议 / 客户沟通 / 速记三套输出符合预期
- [ ] 用户抽检 10 场，至少 8 场"稍改就能发"
- [ ] 单场成本与耗时记录（目标：60 分钟音频 ≤5 分钟出稿，ASR ≤1 元/小时）

## E. 分发

- [ ] 飞书卡片到个人：标题、摘要、待办、按钮跳转正常
- [ ] 飞书卡片到群：群里能看到、按钮能打开
- [ ] 网站回调：HMAC 校验通过，官网能跳详情
- [ ] 分享链接：非本人打开 `/s/...` 能看到纪要并播放音频；过期/篡改链接返回 403
- [ ] 邮件：真实 SMTP 发出 HTML 邮件，中文不乱码
- [ ] 失败重试与 DeliveryLog 可查

## F. 运维

- [ ] 日志落盘 + 轮转（uvicorn/Caddy）
- [ ] 90 天清理任务在跑（启动日志能看到清理条数）
- [ ] 每日备份已跑通（`scripts/backup.py`），并演练过一次恢复
- [ ] 监控：`/health` 探活；磁盘告警
- [ ] 成本看板：`/mine` 或 `/api/v1/stats`

## G. 安全

- [ ] 凭据全部在 `~/.mm`（0600），仓库无明文（提交前跑敏感信息扫描）
- [ ] 签名 URL 1 小时过期；篡改返回 403
- [ ] 录音按 open_id 隔离，越权返回 404
- [ ] 会话 token 7 天过期；服务端可强制失效（改 SECRET_KEY）
- [ ] 上传大小上限 120MB/段，非音频 400

## H. 体检与质量

- [ ] `python scripts/doctor.py` 退出码 0（只剩 mock 提醒）
- [ ] `python scripts/vendor_smoke.py` 两项 reachable=true
- [ ] `ruff check` 全绿；`pytest -q` 全绿
- [ ] 90 分钟压测跑过（`scripts/load_90min.py --minutes 90 --clean`）

## 上线节奏建议

1. 周一到周三：接真实凭据，跑通「真机录音 → 腾讯 ASR → DeepSeek → 飞书卡片」。
2. 周三到周四：10 人试点（测试部门），收集 20 场真实录音调质量。
3. 周五：全公司发布 + 发使用说明（录音放置、勿锁屏、等待 1–5 分钟）。
