# Trace Voice · 项目总览

> 飞书工作台里的「录音 → 转写 → AI 纪要 → 飞书文档 / 卡片」一体化工具。
> 仓库目录：`feishu-voice-recorder`；生产地址：https://voice.traceic.com:5266

## 1. 是什么

员工在飞书工作台打开 Trace Voice，用手机录会议（或会谈）音频；系统自动完成：

1. 分段上传（每段 5 分钟，弱网不中断）
2. 语音转写（阿里云 `qwen-audio-3.1-asr-flash-filetrans`，带说话人分离与时间戳）
3. AI 生成结构化纪要（摘要 / 要点 / 决策 / 待办 / 风险，阿里云 `qwen3.8-flash`）
4. 同步为**飞书云文档**并转交员工本人
5. 推送**飞书卡片**通知（含文档与在线纪要入口）
6. 回调公司网站（HMAC 签名）与邮件（可选）

## 2. 架构

```
飞书客户端（手机）
  └─ 网页应用 H5  ──HTTPS──>  uvicorn/FastAPI（5266, TLS）
                                 ├─ /api/v1/recordings     录音会话、分段上传
                                 ├─ /api/v1/auth/*         飞书免登 → 会话 token
                                 ├─ /media/*               签名音频（1h）
                                 └─ Worker（DB 队列）
                                      ├─ ffmpeg 合并分段
                                      ├─ 阿里云 filetrans 转写（含 speaker）
                                      ├─ qwen3.8-flash 生成纪要
                                      ├─ 飞书 docx 创建 + 转交本人
                                      └─ 飞书卡片 / 网站回调 / 邮件

飞书长连接（feishu-events 服务）
  └─ im.message.receive_v1 → 群里 @机器人 发「录音」回入口
```

- 后端：FastAPI + SQLAlchemy + SQLite（可切 PostgreSQL）+ ffmpeg（imageio-ffmpeg 兜底）
- 前端：单页 H5（无构建步骤），`getUserMedia` + 16k WAV 编码，五次分段复用同一音频流
- 部署：Rocky Linux 8.10，systemd 两个服务，uvicorn 直接提供 TLS（Let's Encrypt DNS-01）

## 3. 功能清单

| 模块 | 能力 |
|---|---|
| 录音 | 开始/结束、电平、屏幕常亮、每 5 分钟落盘、弱网队列重试、断点续录 |
| 登录 | 飞书网页应用免登；生产强制登录（401），登录失效自动重登 + 门禁按钮 |
| 转写 | 说话人分离（发言人1/2…）、句级时间戳、异步任务轮询 |
| 纪要 | 三套场景模板（会议/客户/速记）、结构化 JSON、失败重试 |
| 文档 | 飞书 docx 自动创建、写入内容、转移拥有者给员工 |
| 分发 | 飞书卡片、分享链接（30 天免登录只读）、网站回调、SMTP 邮件 |
| 管理 | 录音记录（时间筛选/标题搜索/移除）、说话人改名、全文搜索、成本统计 |

## 5. 关键约束

- 手机录音必须 **HTTPS**（浏览器安全上下文要求），且飞书 WebView 的麦克风权限由客户端记忆。
- 飞书小程序已停止迭代，因此入口是**网页应用**；官方 JSAPI 录音单段上限 10 分钟，本项目用 `getUserMedia` 自采，不受该限制。
- 说话人分离是「区分发言人编号」，不是实名声纹；误判时可在详情页改名并重新生成纪要。
- 生产环境凭据统一在 `~/.mm/`（0600），服务器 env 在 `/etc/feishu-minutes/env`，仓库内不含任何明文密钥。
