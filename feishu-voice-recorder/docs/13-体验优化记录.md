# 体验评估与优化记录（2026-11-20）

> 评估对象：Trace Voice（feishu-voice-recorder），当前已上线 `https://voice.example.com:5266`。
> 评估视角：**最终用户（员工）体验优先**，同时覆盖安全、数据与运维。
> 评估方法：只读代码/文档审查 + 浏览器端到端验证 + 生产 API 回归，未修改生产数据。

## 一、评估结论

**Conditional Go**：核心流程（录音→转写→纪要→文档→卡片）已跑通且生产回归通过；
P0 未发现；主要问题集中在**异常路径的用户体验与可恢复性**，已在 5 轮内修复。
剩余 P2/P3 为运维增强项，不阻断使用。

## 五、补充优化（P2/P3 收尾）

| 项 | 实现 | 验证 |
|---|---|---|
| 接口限流 | 按 open_id 令牌桶，429 + Retry-After | 单测：连续创建触发 429 |
| 分享撤销 | `share_revocations` 表 + 撤销/恢复接口 + 详情页按钮 | 生产实测：撤销后 shared API 403，恢复后 200 |
| 分享审计 | `share_accesses` 记录 IP/UA/时间 | 单测断言访问落库 |
| Worker 并发 | `FM_WORKER_COUNT`（默认 2），原子认领 | 生产：2 个 worker 启动，任务不重复 |
| 监控告警 | `/health` 增强、`/api/v1/ops/health`、看门狗、飞书文本告警、healthcheck 脚本 | 生产 ops 快照返回队列/磁盘/失败数 |
| 成本透明 | stats 返回 `price_per_hour`，可配 `FM_ASR_PRICE_PER_HOUR` | 单测/接口 |
| 标题与归档 | 默认标题 `AI录音-日期-用户名`；文档自动归入云盘「AI录音」目录 | 生产实测：文档出现在目录内 |
