# 飞书应用配置清单（自建应用）

> 目标：把「纪要录音」挂到企业工作台，具备小程序入口、机器人消息、云文档、任务能力。
> 权限 scope 名称以开放平台当前版本为准（TBD-A 调研结果回填）。

## 1. 创建应用

1. 开放平台 → 开发者后台 → 创建**企业自建应用**，名称「纪要录音」，图标、描述按公司规范。
2. 开启能力：
   - **小程序**（移动端入口，工作台可见）
   - **机器人**（发纪要卡片到群/个人）
   - 网页应用（可选，PC 端兜底录音页）
3. 记录 `App ID` / `App Secret`，存放于 `~/.mm/feishu-minutes`（0600），**不入仓库**。

## 2. 权限（scope）清单

| 用途 | scope（待核对） |
|---|---|
| 发消息/卡片 | `im:message:send_as_bot`、`im:message` |
| 读群/群成员 | `im:chat:readonly`、`im:chat.members:readonly` |
| 读用户信息（免登换 open_id） | `contact:user.base:readonly`、`authen:user.id:read` |
| 创建飞书文档 | `docx:document`、`drive:drive` |
| 任务同步（P2） | `task:task:write` |
| 音频存储/播放（飞书内） | 无需，存自有对象存储 |

> 小程序录音需要额外声明**隐私协议**（麦克风用途），首次使用弹授权。

## 3. 发布

- 自建应用不走上架审核，但需**管理员在管理后台发布**并设置可用范围（全公司或指定部门）。
- 小程序版本：开发版 → 体验版 → 正式版；先体验版跑通再全量。

## 4. 回调与安全

- 事件订阅（可选）：`im.message.receive_v1`（群里 @机器人 触发录音/查询）。
- 请求校验：Verification Token / Encrypt Key；服务器 IP 白名单。
- 应用 secret、SMTP 密码一律 `~/.mm/` + 环境变量注入，仓库内只留占位符。
