# 开发与部署

## 本地跑通（全程 mock，无需任何凭据）

```bash
cd feishu-minutes
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt

cd backend
FM_SYNC_PIPELINE=true ../.venv/bin/python -m uvicorn app.main:app --port 8000 --reload
```

打开 <http://127.0.0.1:8000/>：桌面浏览器里点「开始录音」会请求麦克风权限；
录一小段 → 结束 → 页面上能看到转写（mock 文本）和纪要。

> 手机上要真机测试，需要 HTTPS 公网地址（getUserMedia 要求安全上下文）。
> 把 `FM_PUBLIC_BASE_URL` 设为公网地址，再用 `deploy/` 里的 Caddy 或任意隧道工具暴露。

## 测试

```bash
cd backend && ../.venv/bin/python -m pytest -q
```

覆盖：WAV 校验/合并、分段上传、签名 URL 校验与篡改拒绝、所有权隔离、finish 前置校验、完整链路（mock）。

## 切真实服务

| 变量 | 值 | 凭据位置 |
|---|---|---|
| `FM_ASR_PROVIDER` | `tencent` | `~/.mm/tencent-asr` |
| `FM_LLM_PROVIDER` | `deepseek` | `~/.mm/deepseek` |
| `FM_FEISHU_MODE` | `real` | `~/.mm/feishu-minutes` |
| `FM_WEBSITE_CALLBACK_URL/SECRET` | 公司网站回调 | `~/.mm/website-callback` |

凭据文件格式：`KEY=VALUE` 每行一条，权限 0600。

## 生产部署（Docker Compose）

```bash
cp .env.example .env   # 填 DOMAIN、FM_PUBLIC_BASE_URL、POSTGRES_PASSWORD 等
docker compose up -d --build
```

- `api`：FastAPI（含 ffmpeg，供 M2 转码用）
- `db`：PostgreSQL 16
- `caddy`：自动 HTTPS，反代到 api
- 数据：`./data`（音频）、`pgdata`（数据库）

## 已知限制（POC 阶段）

- 流水线用后台线程，进程重启会中断 → M2 换 Redis/RQ。
- 只接受 WAV 分段；浏览器端已统一编码为 16k 单声道 WAV。
- 飞书免登未接：当前用 `X-Employee-Open-Id` 头模拟身份（默认 demo）。
- 详情页 `/d/{id}` 的 open_id 取 `localStorage.fm_uid`，默认 demo。
