## 飞书应用配置要点（2026-11-20 核实官方文档）

- `/authen/v1/access_token` 与 `/authen/v1/user_info` 调用**不需要任何 API 权限**，open_id 直接返回。
- 邮箱字段需要 `contact:user.email:readonly`；user_id 需要 `contact:user.employee_id:readonly`（可选）。
- 发消息需要 `im:message:send_as_bot`。
- 不存在 `authen:user.id:read` 这个 scope（此前文档写错，已修正）。

## 历史记录：公网与 HTTPS（决策过程）

- 用户给的公网地址是 `http://voice.traceic.com:5266`，DNS 指向 `58.246.51.170`（DNSPod，非 Cloudflare）。
- 从本机与服务器实测：公网 5266 未通（NAT/防火墙未映射或未生效）。
- **手机录音必须有 HTTPS**（getUserMedia 只在安全上下文可用），HTTP 地址无法录音。
- 当前临时方案：本机跑 `cloudflared` 快速隧道指向服务器 5266，得到 HTTPS 地址用于验证；
  隧道随本机/重启变化，不适合长期。
- 可选正式方案：
  1. Cloudflare 命名隧道（需要 Cloudflare API Token / 账号），把 `voice.traceic.com` 指到隧道；
  2. DNSPod API Token + certbot DNS-01，在服务器 nginx 上签 Let's Encrypt 证书；
  3. 打通公网 80/443 → 服务器，用 HTTP-01 自动签证书。
