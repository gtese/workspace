# 07 — Slurm 新人快速上手

> 面向第一次使用集群的同事：从登录到提交第一个作业，尽量只保留必要步骤。

---

## 0. 整体流程

```text
浏览器登录堡垒机
  → 左侧「运维」→ 用户配置「根目录」
  → 资产列表找到目标服务器
  → 「访问」列点击 SSH
  → 进入 131 / 132 / 133 终端
  → 创建共享目录 /eda/workspace/users/$USER
  → 写作业脚本
  → sbatch 提交
  → squeue / sacct 查看
```

> ⚠️ 131-133 只作为登录/提交节点使用；实际计算作业运行在 **eda151-155**（默认分区 `eda15x`）。

---

## 1. 通过堡垒机登录

1. 浏览器打开堡垒机 Web 控制台并登录。
2. 左侧导航栏点击 **「运维」**。
3. 在 **用户配置** 中选择 **「根目录」**。
4. 在右侧资产列表中找到目标服务器：
   - `172.16.50.131` / `trivm131`
   - `172.16.50.132` / `trivm132`
   - `172.16.50.133` / `trivm133`
5. 在 **「访问」** 列点击对应协议：
   - Linux 登录节点选择 **SSH**
   - 如需图形桌面，选择 **RDP**
6. 打开终端后确认：

```bash
hostname
whoami
```

> 如果堡垒机系统管理中未配置该服务器的账号，会提示手动输入账号和密码。
> 请输入自己的 **域账号 / 域密码** 登录，不需要使用 root。

---

## 2. 创建自己的 Slurm 目录

所有作业数据必须放共享存储：

```bash
mkdir -p /eda/workspace/users/$USER/slurm-logs
cd /eda/workspace/users/$USER
```

目录结构示例：

```text
/eda/workspace/users/<你的账号>/
├── slurm-logs/        # 作业输出
├── hello.slurm        # 作业脚本
└── ...                # 你的项目文件
```

> ❌ 不要把作业文件放 `/home/$USER`：各节点 home 独立，计算节点读不到。
> ✅ 统一使用 `/eda/workspace/users/$USER`。

---

## 3. 提交一条命令到指定节点

如果只是想在某台机器上跑一条命令：

```bash
sbatch -p eda15x \
  -w 172.16.50.151 \
  -N1 -c1 --mem=1G --time=00:05:00 \
  -o /eda/workspace/users/%u/slurm-logs/onecmd-%j.out \
  --wrap="hostname -f"
```

说明：

| 参数 | 含义 |
|---|---|
| `-p eda15x` | 使用默认分区（151-155） |
| `-w 172.16.50.151` | 指定运行节点 |
| `-N1` | 1 个节点 |
| `-c1` | 1 个 CPU 核 |
| `--mem=1G` | 1GB 内存 |
| `--time=00:05:00` | 最长 5 分钟 |
| `-o .../%u.../%j.out` | 输出文件，`%u`=用户名，`%j`=JobID |
| `--wrap` | 直接执行引号里的命令 |

提交后会返回类似：

```text
Submitted batch job 3001
```

查看输出：

```bash
cat /eda/workspace/users/$USER/slurm-logs/onecmd-3001.out
```

## 4. 提交脚本到分区

### 4.1 写脚本

```bash
cat > hello.slurm <<'EOF'
#!/bin/bash
#SBATCH --job-name=hello
#SBATCH --partition=eda15x
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=4
#SBATCH --mem=16G
#SBATCH --time=00:30:00
#SBATCH --account=staff
#SBATCH --output=/eda/workspace/users/%u/slurm-logs/%x-%j.out
#SBATCH --error=/eda/workspace/users/%u/slurm-logs/%x-%j.err

cd "/eda/workspace/users/$USER"

echo "hostname : $(hostname -f)"
echo "node     : $SLURM_JOB_NODELIST"
echo "jobid    : $SLURM_JOB_ID"
echo "start    : $(date)"
sleep 30
echo "end      : $(date)"
EOF
```

### 4.2 提交

```bash
sbatch hello.slurm
```

或显式指定分区：

```bash
sbatch -p eda15x hello.slurm
```

> 不写 `-p` 时默认就是 `eda15x`。

## 5. 查看当前作业和历史作业

### 当前排队/运行

```bash
squeue -u $USER
```

### 查看某个作业

```bash
squeue -j <JobID>
scontrol show job <JobID>
```

### 最近 72 小时已结束作业

集群设置：

```text
MinJobAge = 259200 秒（72 小时）
```

因此可以用：

```bash
squeue --states=all -u $USER
```

### 历史作业（推荐）

```bash
sacct -u $USER -S today
sacct -j <JobID> -o JobID,Partition,JobName,State,ExitCode,Elapsed,NodeList
```

### 取消作业

```bash
scancel <JobID>
scancel -u $USER
```

## 6. 常见错误

| 现象 | 原因 | 解决 |
|---|---|---|
| 提交后没有输出文件 | `--output` 的父目录不存在 | 先 `mkdir -p /eda/workspace/users/$USER/slurm-logs` |
| `#SBATCH` 里写了 `$USER` | Slurm 不展开 shell 变量 | 改成 `%u` |
| `Invalid partition` | 分区名错误 | 用 `eda15x` |
| 作业一直 PENDING | 资源暂时不足 | `squeue -j <ID> -o "%.10i %.8T %.30R"` |
| 计算节点读不到文件 | 作业数据放在 `/home` | 改放 `/eda/workspace/users/$USER` |
| EDA 工具 License 失败 | 未配置 License | `export LM_LICENSE_FILE=27000@172.16.50.121` |

## 7. 最常用命令速查

```bash
# 目录
mkdir -p /eda/workspace/users/$USER/slurm-logs
cd /eda/workspace/users/$USER

# 查看分区
sinfo

# 提交
sbatch hello.slurm

# 看自己的活动作业
squeue -u $USER

# 看自己的历史作业
sacct -u $USER -S today

# 看最近 72h 已结束
squeue --states=all -u $USER

# 取消
scancel <JobID>
```
