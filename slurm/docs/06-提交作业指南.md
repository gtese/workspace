# 06 — 提交作业指南

> 适用：tricluster 新集群（172.16.50.123 提交，151-155 计算）。

---

## 1. 登录

```bash
ssh <你的账号>@172.16.50.123
```

或浏览器打开：https://edas.tri.local（SSO 登录）。

---

## 2. 准备共享目录

```bash
mkdir -p /eda/workspace/users/$USER/slurm-logs
cd /eda/workspace/users/$USER
```

> ⚠️ 作业数据必须放在 `/eda/workspace/users/$USER`，不要放在 `/home/$USER`。
> 公共目录：`transfer/` 临时传输、`handoff/` 协作、`share/` 全员共享。

---

## 3. 查看分区

```bash
sinfo
sinfo -o "%20P %5a %6D %7t %25N"
```

当前默认分区：

```text
eda15x*   172.16.50.[151-155]
```

不指定 `-p` 时自动使用 `eda15x`。

---

## 4. 第一个作业

```bash
cat > hello.slurm <<'EOF'
#!/bin/bash
#SBATCH --job-name=hello
#SBATCH --partition=eda15x
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=4
#SBATCH --mem=16G
#SBATCH --time=00:30:00
#SBATCH --account=staff
#SBATCH --output=/eda/workspace/users/%u/slurm-logs/%x-%j.out
#SBATCH --error=/eda/workspace/users/%u/slurm-logs/%x-%j.err

echo "hostname : $(hostname -f)"
echo "node     : $SLURM_JOB_NODELIST"
echo "jobid    : $SLURM_JOB_ID"
echo "start    : $(date)"
EOF

sbatch hello.slurm
```

> `#SBATCH` 中不要写 `$USER`，用 `%u`（用户名）、`%x`（作业名）、`%j`（JobID）。
> `--output` 的父目录必须已存在。

---

## 5. 查看作业

```bash
squeue -u $USER
squeue -j <JobID>
scontrol show job <JobID>
sacct -j <JobID> -o JobID,Partition,State,ExitCode,Elapsed,NodeList
```

输出文件：

```bash
ls -la /eda/workspace/users/$USER/slurm-logs/
cat /eda/workspace/users/$USER/slurm-logs/hello-<JobID>.out
cat /eda/workspace/users/$USER/slurm-logs/hello-<JobID>.err
```

取消：

```bash
scancel <JobID>
```

## 6. EDA 作业示例（Design Compiler）

```bash
cat > dc.slurm <<'EOF'
#!/bin/bash
#SBATCH --job-name=dc
#SBATCH --partition=eda15x
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=8
#SBATCH --mem=64G
#SBATCH --time=04:00:00
#SBATCH --account=staff
#SBATCH --output=/eda/workspace/users/%u/slurm-logs/%x-%j.out
#SBATCH --error=/eda/workspace/users/%u/slurm-logs/%x-%j.err

set -euo pipefail

cd "/eda/workspace/users/$USER/dc_project"

export PATH=/eda/env/commands/bin:$PATH
export LM_LICENSE_FILE=27000@172.16.50.121
export SNPSLMD_LICENSE_FILE=27000@172.16.50.121

echo "node : $(hostname -f)"
echo "start: $(date)"

dc_shell -f synth.tcl

echo "end  : $(date)"
EOF

sbatch dc.slurm
```

> `synth.tcl` 是 Design Compiler 的综合脚本，需要自己准备（工艺库、RTL、约束、输出）。

```text
登录 https://edas.tri.local
→ Jobs → Job Composer

```

或在 OOD Shell 中直接 `sbatch`。

---

## 8. 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `FAILED 1:0`，无输出 | `--output` 目录不存在 | `mkdir -p /eda/workspace/users/$USER/slurm-logs` |
| PENDING (Resources) | 请求资源超过空闲 | 降低 `--mem` / `--cpus-per-task` / `--nodes` |
| License checkout failed | License 不可达/用尽 | 检查 `27000@172.16.50.121` |
| 提交报 `Invalid partition` | 分区名错误 | 使用 `eda15x` |
| `srun` 卡住 | 控制节点回连端口未放行 | 联系管理员运行 `fix-srun-return-ports.sh` |
