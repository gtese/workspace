## SELinux

OOD 依赖：

```bash
setsebool -P httpd_can_connect_ldap on
setsebool -P httpd_can_network_connect on
setsebool -P httpd_enable_homedirs on
setsebool -P httpd_read_user_content on
setsebool -P ondemand_manage_user_home_dir on
setsebool -P ondemand_use_slurm on
setsebool -P ondemand_use_ldap on
setsebool -P ondemand_use_sssd on
```

自定义策略：

- `/etc/selinux/oodhome.cil`
- `/etc/selinux/ood_sudo.cil`
- `/etc/selinux/ood_pun_home.cil`

加载：

```bash
for f in /etc/selinux/oodhome.cil /etc/selinux/ood_sudo.cil /etc/selinux/ood_pun_home.cil; do
  [ -f "$f" ] && semodule -i "$f"
done
```

对应脚本：

```bash
bash scripts/fix-ood-pun-latency.sh
bash scripts/fix-ood-missing-home.sh
```

## 防火墙

控制节点需要放行计算网段到 6817-6819 以及 srun 回连端口：

```bash
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="172.16.50.0/24" port port="6817-6819" protocol="tcp" accept'
firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="172.16.50.0/24" port port="32768-60999" protocol="tcp" accept'
firewall-cmd --reload
```

> `32768-60999` 用于 srun 交互式作业回连；不放行会导致 srun 卡 32 秒。
