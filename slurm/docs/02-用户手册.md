## 3. 目录约定

| 用途 | 路径 | 说明 |
|---|---|---|
| **作业数据** | `/eda/workspace/users/<用户名>/` | 管理员创建，仅本人可读写 |
| 临时传输 | `/eda/workspace/transfer/` | 777，无备份，随时可能清理 |
| 交接/协作 | `/eda/workspace/handoff/` | 2770，正式员工组可读写 |
| 全员共享 | `/eda/workspace/share/` | 777，无访问控制 |
| 个人 home | `/home/<用户名>/` | ⚠️ 各节点独立，作业勿依赖 |
| EDA 工具 | `/eda/apps/` | 只读 |
| EDA 命令 | `/eda/env/commands/bin` | 加入 PATH |

### 最重要的规则

**作业数据必须放 `/eda/workspace/users/<用户名>`！**

```bash
mkdir -p /eda/workspace/users/$USER
cd /eda/workspace/users/$USER
sbatch myjob.sh
```

## 4. 提交作业

### 方式 1：命令行

```bash
cd /eda/workspace/users/$USER

cat > hello.slurm <<'EOF'
#!/bin/bash
#SBATCH --job-name=hello
#SBATCH --partition=eda15x
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=4
#SBATCH --mem=16G
#SBATCH --time=00:30:00
#SBATCH --account=staff
#SBATCH --output=/eda/workspace/users/%u/slurm-logs/%x-%j.out
#SBATCH --error=/eda/workspace/users/%u/slurm-logs/%x-%j.err

echo "hostname: $(hostname -f)"
echo "nodelist: $SLURM_JOB_NODELIST"
EOF

mkdir -p /eda/workspace/users/$USER/slurm-logs
sbatch hello.slurm
```

> ⚠️ `#SBATCH --output` 里用 Slurm 占位符 `%u` / `%x` / `%j`，不要写 `$USER`。
> `--output` 的父目录必须提前存在。

### 方式 2：OOD Job Composer

```text
登录 OOD → Jobs → Job Composer → New Job → 编辑 → Submit
```

### 方式 3：OOD Shell

```bash
cd /eda/workspace/users/$USER
sbatch hello.slurm
```

## 5. 常用命令

```bash
sinfo -o "%20P %5a %6D %7t %25N"     # 分区概览
squeue -u $USER                      # 我的作业
squeue -j <JobID>                    # 指定作业
scontrol show job <JobID>            # 作业详情
sacct -j <JobID>                     # 历史/状态
scancel <JobID>                      # 取消作业
scancel -u $USER                     # 取消我的全部
```

### 作业输出

```bash
ls -la /eda/workspace/users/$USER/slurm-logs/
cat /eda/workspace/users/$USER/slurm-logs/<jobname>-<JobID>.out
cat /eda/workspace/users/$USER/slurm-logs/<jobname>-<JobID>.err
```

## 7. 常见问题

### 作业一直 PENDING

```bash
squeue -j <JobID> -o "%.10i %.9P %.8T %.10M %.30R"
```

常见原因：内存/CPU 请求超过节点剩余资源、时间限制、账户限制。

### 作业 FAILED 1:0，没有输出文件

通常是 `--output` 的父目录不存在：

```bash
mkdir -p /eda/workspace/users/$USER/slurm-logs
```

再重新提交。

### License 失败

```bash
export LM_LICENSE_FILE=27000@172.16.50.121
```

检查 License 服务可达：

```bash
timeout 5 bash -c '</dev/tcp/172.16.50.121/27000'
```

### OOD 打不开 / 登录 500

联系管理员；管理员可检查：

```bash
/opt/ood/nginx_stage/sbin/nginx_stage nginx_clean -f -u <用户名>
journalctl -t ood-pun-prehook -n 20
tail -50 /var/log/ondemand-nginx/<用户名>/error.log
```
